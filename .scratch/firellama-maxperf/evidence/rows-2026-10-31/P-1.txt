Here's a thinking process:

1.  **Understand User Request:**
   - **Task:** Write a Python function to insert a key into a Binary Search Tree (BST).
   - **Requirement:** Explain how it works.
   - **Language:** Python

2.  **Define BST Properties:**
   - A Binary Search Tree is a node-based binary tree data structure with the following properties:
     - The left subtree of a node contains only nodes with keys less than the node's key.
     - The right subtree of a node contains only nodes with keys greater than the node's key
